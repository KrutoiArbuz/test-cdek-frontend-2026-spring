# Новостной виджет — CDEK

Универсальный компонент новостного блока. Получает данные с API, отображает новости с пагинацией, поддерживает два варианта отображения и все состояния — загрузку, ошибку, пустой список.

## Демо

[Демо](https://test-cdek-frontend-2026-spring.vercel.app/)

На странице три варианта компонента: **Новости компании**, **Бизнес** и **Пустой**.

## Запуск

Убедитесь, что установлен Node.js (v18+).

**1. Установите зависимости:**

```bash
npm install
```

**2. Создайте `.env` файл:**

```
VITE_API_URL=.../api/v1

VITE_API_BASE_URL=...
```

**3. Запустите dev-сервер:**

```bash
npm run dev
```

Приложение доступно по адресу: http://localhost:5173

## Принятые решения

**Адаптивность через CSS Container Queries** — виджет реагирует на ширину своего контейнера, а не вьюпорта. Два экземпляра рядом (589px и 347px) независимо переключаются между десктопным и мобильным режимом.

**Кэширование** — TanStack Query, `staleTime: 5 минут`. Возврат на просмотренную страницу — без повторного запроса.

**Изображения** — `srcSet` с четырьмя размерами (`s / m / l / hd`), браузер выбирает оптимальный под DPR. `loading="lazy"` на всех обложках.
